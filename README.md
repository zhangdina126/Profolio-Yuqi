# YUQI Portfolio

The restored original YUQI designer website: monochrome typography with a blue concept image.

## Files

- `index.html`: website content
- `style.css`: responsive styles
- `form-feeling.webp`: concept artwork

## GitHub Pages

In Settings → Pages choose **Deploy from a branch**, **main**, and **/(root)**, then Save.

The site uses relative asset URLs and needs no build step.
